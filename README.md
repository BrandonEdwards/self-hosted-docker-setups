# Self-hosted Docker Setups

A collection of my docker-compose files for my homelab self-hosted services. Currently hosted on an old Dell laptop running Linux Mint, but we shall see where we go from here.

---

## Alphabetical list of services hosted (linked to their respective GitHub repositories)

* [Immich](https://github.com/immich-app/immich) (Server + ML container + Redis + Database)
* [Navidrome](https://github.com/navidrome/navidrome)
* [Nginx Proxy Manager](https://hub.docker.com/r/jc21/nginx-proxy-manager/)
* [Plex](https://github.com/linuxserver/docker-plex) (Using the linuxserver Docker version)
* [qBittorrent + ProtonVPN](https://github.com/Chillsmeit/qBittorrent-ProtonVPN-Guide)
